# Barford Golf Society 2027 — Mobile Admin Fixed

This version specifically fixes the Scores administrator dashboard on phones.

Improvements:
- true full-screen mobile dashboard
- no sideways scrolling
- swipeable admin section tabs
- sticky heading and close button
- one-column forms
- one player score card per row
- full-width buttons
- clearer spacing and labels
- stacked confirmation dialogs
- improved support for narrow phones

The Scores system remains development-only and uses isolated browser localStorage.
